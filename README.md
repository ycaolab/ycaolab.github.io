# Y. Cao Lab website

Website of the Y. Cao Lab (Decision and Information Sampling) at Otto-von-Guericke University Magdeburg.

Built with Jekyll. To run it locally:

    bundle install
    bundle exec jekyll serve

Then open http://localhost:4000.

Content lives in `_pages/` (pages) and `_data/` (publications, team, news, collaborators). The home video is in `images/hero/`.

Layout derived from the Allan Lab Jekyll template (MIT License).
